Y_归层工具 V1.0 —— 安装与使用
================================================================

  AutoCAD 自动归层插件。按图元类型把新画的图元落到指定图层，
  画完把当前图层还回去。

  默认是「停用」状态，不配置就完全不介入，不会动你任何东西。


一、装上去
----------------------------------------------------------------

  插件就一个文件：Y_归层工具V1.0.dll

  三种装法，选一种。

  ── 装法 1：跟其他插件一起自动加载（推荐）──

  1. 把 Y_归层工具V1.0.dll 放进一个固定文件夹，比如：

         C:\Users\<你的用户名>\Documents\Y-CADSettings\CJ\Y_归层工具\

  2. 打开加载清单（记事本就行）：

         C:\Users\<你的用户名>\Documents\Y-CADSettings\CJ\
         AutoCAD Duotab\config\AppLoader.xml

     在 </settings> 前面加一条：

         <app isfolder="False" addtrustpath="False"
              loadinallversion="True" loaderversion="0.0.0.0">
         C:\Users\<你的用户名>\Documents\Y-CADSettings\CJ\Y_归层工具\Y_归层工具V1.0.dll
         </app>

     （实际要写成一整行，中间不能换行）

  3. 完全关闭 AutoCAD，重新打开

  ⚠ 改清单前必须先关掉 CAD。Duotab 运行时会回写这个文件，
    开着改会被冲掉（实测还丢过别的条目）。


  ── 装法 2：NETLOAD（临时，只对本次 CAD 有效）──

     命令行输  NETLOAD  →  选「Y_归层工具V1.0.dll」

     关掉 CAD 就失效了，下次要重来。


  ── 装法 3：APPLOAD 启动组（永久，不动 Duotab）──

     1. 命令行输  APPLOAD  回车
     2. 右下角「启动组」，点「内容」
     3. 「添加」→ 选「Y_归层工具V1.0.dll」→ 打开
     4. 两个窗口都点「关闭」

     记的是绝对路径，挪文件夹要重新加。


  ── 怎么确认装好了 ──

  命令行输 QH：

    · 面板弹出来           = 装好了
    · 提示「未知命令」     = 没加载上，看第六节

  同时画图区顶部中间会出现状态条，说明界面部分也起来了。
  插件目录里会自动多出一个 AutoLayer.ini —— 有它说明插件确实被加载了。

  ⚠ 从旧版（以前叫「自动归层」）升上来的，dll 文件名变了，
    AppLoader.xml 里那一行必须改成 Y_归层工具V1.0.dll，
    不改的话 CAD 会去找一个已经不存在的文件，等于没装。
    配置不用动：AutoLayer.ini 原样留着，格式没变。


二、第一次用
----------------------------------------------------------------

  1. 面板顶部把总开关打开
  2. 给要归层的类别选目标图层
     · 点「目标图层」那一列，从图纸现有图层里选
     · 留空 = 这一类不归层（保持原样）
  3. 正常画图

  例：「线段」配了 E-04，你画 LINE、CIRCLE、ARC、PLINE、矩形，
  图元就直接落在 E-04 上，画完当前图层还回去。

  面板关掉不影响使用，配置已经存了。


三、日常用法
----------------------------------------------------------------

  ── 面板（QH）──

  七个类别一栏一个：目标图层、当前用哪一层、颜色。
  改完点「完成」保存并关闭。

  支持的 7 类：

      线段    直线、多段线、圆、圆弧、椭圆、样条、多线、射线、
              构造线、圆环、螺旋、修订云线、徒手画、矩形、多边形
      文字    单行文字、多行文字、弧线文字
      标注    线性 / 对齐 / 角度 / 直径 / 半径 / 坐标 / 基线 /
              连续 / 折弯 / 弧长 / 快速标注、形位公差
      填充    图案填充、渐变填充、实体填充
      引线    引线、快速引线、多重引线
      块      插入块
      视口    MVIEW / VPORTS / SOLVIEW（只在布局里用得上）

  目标图层不存在会自动新建，颜色用配置时记住的那个色。
  图层被冻结 / 关闭 / 锁定时会自动解冻、打开、解锁。


  ── 一类配多个图层（图层池）──

  点这一行下面的「＋」→ 弹出图纸图层清单（带搜索框）→ 勾几个 → 确定

  勾完这一行是收起的，只显示一行摘要：

        ▸ 3 层   E-04 造型线   ＋

  点摘要那一行才铺开成 chip：

        ▾ 3 层   E-04 造型线   ＋
        [E-04 造型线 ▮7 ✕] [E-05 辅助线 ▮3 ✕] [E-01 结构 ▮5 ✕]

    · 蓝框那个 = 下一条命令会用它；点别的就挪过去
    · 点 chip 上的色块 = 调出 CAD 选色板，改这一个图层的颜色（各层各记）
    · 点 ✕ = 把这一层从池里去掉
    · 按住 chip 左右拖 = 调顺序，圆盘扇区跟着这个顺序走
    · 也可以用输入框，分号隔开：  E-04 造型线 ; E-05 辅助线 ; E-01 结构

  换层只影响下一条命令，手上这条线画到一半不会跳到别的层去。


  ── 状态条 ──

  画图区顶部居中一个小胶囊：

        ● Y_归层工具 │ 平面图 │ ■ E-04 造型线

    · 绿点 = 开着，灰点 + 橙字「已关闭」= 关着
    · 中间是当前配置名
    · 右边那个色块就是下一条命令会落到的图层，颜色跟图纸里一致
    · 换层之后它会亮一下，显示换到了哪一层

  位置固定，没有开关。


  ── 点配置名切配置 ──

  鼠标移到状态条上的配置名（那个蓝色的名字）→ 会浮一层淡底、光标变手型。
  点一下，下面弹出配置清单，当前在用的那条是实心蓝底 + ✓。
  点任意一条就切过去，清单收起。

  点清单外面、或者再点一下配置名，清单收起。

  清单从状态条底下长出来、左右居中；配置名短的时候，胶囊会跟着撑到
  跟清单一样宽，收起来再缩回去。

  点它不会把焦点从 CAD 抢走 —— 画到一半（命令还在进行中）也能点开换配置，
  当前命令不会被打断。

  只有配置名那一小块能点，状态条其余地方照旧穿透到画图区。


  ── 调整配置顺序 ──

  点开面板里的「配置」下拉列表，按住某一条往上 / 往下拖。
  拖到哪一条上面，那一条的上边会出一道蓝线，告诉你松手会落在哪儿。
  松手立刻存盘，状态条那份清单也跟着这个顺序走。

  只是点一下（不拖）还是照常选中那条配置；拖顺序不会换掉当前在用的配置。


  ── 右键长按圆盘 ──

  在画图区按住右键不放（默认 0.18 秒），鼠标位置弹出一个圆盘：

    · 扇区 = 你最近画的那一类配的几个图层
    · 圆盘的圆心就是你按右键的那个点，跟着手走
    · 鼠标移到哪一格，中心显示那层的名字
    · 松手 = 换到那一层；松手在正中间 = 取消；按 Esc 也取消

  2~8 个图层排一圈，9~16 个排成内外两圈。
  圆盘是毛玻璃的：弹出前把底下那块图纸抓一帧、糊掉再垫在下面，
  底下的线不会从字上穿过去。

  命令跑到一半时完全不介入（那会儿右键菜单里是「取消 / 闭合 / 端点」
  这类命令选项，抢了等于把人卡在命令里）。

  想先看看圆盘长什么样：命令行输 ALPIE，鼠标位置直接弹一个出来。


  ── 设置窗口 ──

  面板右上角那个滑杆小图标打开（命令行输 ALSET 也行）：

        面板
          快捷键     [Ctrl+Shift+Q]  [清除]
          CAD 命令   [ GH          ]  [清除]
        圆盘
          触发方式   [右键长按] [侧键后退] [侧键前进] [关闭]
          长按时长   ──●────────  180 ms

  快捷键：点一下框，然后直接按下想用的组合键，不用手打。
    · 必须带 Ctrl 或 Alt 之一
    · 按 Esc 取消录入、按退格清成「无」
    · 清成「无」之后只剩 QH 命令能开面板

  CAD 命令：给面板起个自己的命令名。填 GH，敲 GH 就等于敲 QH。
    · 2~20 个字符，只能字母、数字、减号、下划线
    · 别用单字母（L / C / M 这些被 CAD 别名占了）
    · 点保存立刻生效，不用重启 CAD

  触发方式：右键长按 / 侧键后退 / 侧键前进 / 关闭。
  长按时长只对「右键长按」有效，100~1000 毫秒。

  ⚠ 侧键没反应，先看有没有鼠标增强工具在跑 —— Quicker、StrokeIt、
    WGestures、罗技 / 雷蛇驱动这类会抢鼠标键，抢了插件就收不到。
    先退掉再试。输 ALMOUSE 能看到到底收没收到。


四、命令一览
----------------------------------------------------------------

  QH        打开 / 关闭配置面板            ← 平时只用这一个
  ALON      启用（不开面板，直接开）
  ALOFF     停用（完全不介入画图）
  ALTOGGLE  启用 / 停用 来回切
  ALSET     打开设置（快捷键 / CAD 命令 / 圆盘触发方式）
  ALPIE     手动弹一次圆盘（试样子 / 临时换层）
  ALSTATUS  在命令行打印当前状态和映射表    ← 排障用
  ALKEY     快捷键为什么不响应              ← 排障用
  ALMOUSE   圆盘 / 侧键为什么不响应          ← 排障用
  ALTRACE   打印最近几次归层记录            ← 排障用
  ALEDIT    在资源管理器里定位到配置文件

  记不住没关系，QH 一个就够。


五、配置文件 AutoLayer.ini
----------------------------------------------------------------

  位置（跟 dll 在同一个文件夹）：

      C:\Users\<你的用户名>\Documents\Y-CADSettings\CJ\
      Y_归层工具\AutoLayer.ini

  首次运行自动生成，不用手动建。想找它：命令行输 ALEDIT 回车，直接跳过去。
  纯文本，记事本就能改，改完重启 CAD 生效。

  长这样：

      ; 分号开头是注释，随便写
      启用 = 是
      当前配置 = 立面

      命令后还原图层 = 是
      自动新建图层 = 是
      自动解冻 = 是
      自动打开图层 = 是
      自动解锁 = 是
      新建图层默认颜色 = 7
      圆盘 = 是
      圆盘按键 = 右键
      圆盘长按毫秒 = 180
      面板快捷键 = Ctrl+Shift+Q
      面板命令 = 无

      [配置: 立面]
      线段 = E-04 立面造型线 | 143 ; E-05 立面辅助线 ; E-01 结构
      当前层.线段 = 2
      文字 =
      标注 = E-12 立面尺寸标注 | rgb(12,200,240) ; E-13 索引标注
      填充 = E-30 填充
      引线 =
      块 = E-15 块 ; E-16 图块 ; E-17 家具块
      视口 =

  规则：

      · 一行「图层名 | 颜色号」，竖线后面是颜色，可以省略
      · 一类配多个图层用分号隔开，先写的排前面
      · 「当前层.xxx = 2」记的是池里用第几个（从 1 开始，不写就是 1）
      · 颜色号 1~255（CAD 标准色号），真彩色写 rgb(12,200,240)
      · 图层名留空 = 这一类不归层
      · 想加一套新配置，就再加一段 [配置: 名字]，名字随便起
      · 图层名不能含这些字符： < > / \ " : ; ? * | , = `

  改坏了会怎样：看不懂的行会被安静跳过，只丢那几条规则。
  实在改烂了，把 AutoLayer.ini 删掉，下次启动 CAD 会自动生成一份默认的。

  dll 所在文件夹没有写入权限时，插件会自动改用
  %AppData%\AutoLayer\AutoLayer.ini；ALSTATUS 里「配置文件」一行能看到实际位置。


六、出问题了怎么查
----------------------------------------------------------------

  ▸ 输 QH 提示「未知命令」

      · 先看插件文件夹里有没有 AutoLayer.ini
        —— 没有 = 插件根本没被加载，跟 QH 命令无关
      · 是不是 AppLoader.xml 里还指着旧的文件名（升级后最常见）
      · 是不是改完 AppLoader.xml 没有完全重启 CAD
      · 打开 AppLoader.xml 确认那一行还在
        —— Duotab 运行时会回写这个文件，可能把你的改动冲掉
      · 输 ALSTATUS 试试，能出东西就说明插件其实加载了

  ▸ NETLOAD 选完 dll 没反应，或者提示不受信任

      这是 CAD 的安全限制（SECURELOAD）挡住了。
      工具 → 选项 → 文件 → 受信任的位置，把 dll 所在文件夹加进去，重启 CAD。

  ▸ 状态条不见了

      · 它固定在画图区顶部居中，没有「关掉」这个状态
      · CAD 最小化、或切到别的图纸时会跟着收起，回来就出现
      · 输 ALSTATUS 能确认插件本身还在不在跑

  ▸ 面板能开，但画线还是落在原来的层

      · 总开关是不是「停用」→ 看面板顶部，或输 ALSTATUS
      · 这一类的目标图层是不是留空了
      · 图层名里有没有非法字符 → 面板会显示红色「名称非法」
      · 输 ALSTATUS 看映射表（[ ] 括起来的是当前用的那个）

  ▸ 长按右键没反应 / 一按右键就弹圆盘

      · 没反应：命令跑到一半时故意不接管
      · 没反应：当前这一类是不是只配了一个图层（只有一个就不弹）
      · 太灵敏：把「圆盘长按毫秒」调到 700 左右
      · 想彻底关掉：「圆盘 = 否」，右键立刻恢复 CAD 原生行为

  ▸ 快捷键按了没反应

      · 先确认 CAD 是当前窗口 —— 前台不是 CAD 时故意不接管
      · 设置里看快捷键那一格是不是「无」
      · 组合里必须带 Ctrl 或 Alt
      · 输 ALKEY，它会直接告诉你卡在哪一步

  ▸ 面板里的中文变成方块 / 乱码

      配置文件要存成 UTF-8。记事本另存为时选 UTF-8。
      插件自己写的文件带了 BOM，正常不会出问题，手改时注意别存成 ANSI。

  ▸ 面板改完配置，关窗口时提示保存失败

      dll 所在文件夹没有写入权限。插件会自动改用
      %AppData%\AutoLayer\AutoLayer.ini，ALSTATUS 里能看到实际用的位置。


七、卸载
----------------------------------------------------------------

  1. 关闭 AutoCAD
  2. 删掉插件文件夹（配置就在里面，一起删干净）
  3. 把 AppLoader.xml 里那一行删掉

  不用改注册表，不用重启系统。


八、兼容性
----------------------------------------------------------------

  · 需要 AutoCAD 2020 ~ 2024（64 位），32 位不支持
  · 只对新画的图元生效，不会回头改已经画好的东西
  · 同时开多个 AutoCAD 窗口时，配置以「最后关面板的那个」为准，
    建议只在一个窗口里改配置
  · 图纸里图层的颜色属于图纸本身，换个文件不会带着走
  · 圆盘最多显示 16 个图层，一个类别别配太多，常用的放前面
