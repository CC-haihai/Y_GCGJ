08

一致性红线 与 验收自查

01 §8 精选 10 条 · 01 §9 精选 7 条

一致性红线 禁止项 · 10 条

  • 01禁止出现 token 表外的颜色。任何 #RRGGBB 必须能在 §2 查到名字；新增颜色只能进 UiTheme + 资源字典。
  • 02禁止渐变与纹理。Linear/RadialGradientBrush、ImageBrush 一律不得用于底色与描边。
  • 03投影只允许 3 处：屏幕胶囊（blur 10）、圆盘（blur 20）、圆盘悬停光晕（blur 22）。窗口内部零投影。
  • 04禁止实心蓝用于"选中"。选中只能是 AccentSoft 底 + AccentLine 标记；实心 Accent 仅限主按钮 / 开关 on / 复选框选中 / 滑杆已选段。
  • 05禁止字体字形当图标（⚙ ◐ ✕ ✓ ●），一律改 Path，画布 12 / 14 / 16。
  • 06禁止字号自由取值：只有 8.5 / 10.5 / 11.5 / 12 / 13.5 / 20 六档，禁止局部覆盖 FontSize。
  • 07禁止控件尺寸自由取值：高度只有 20/22/26/29/30/32/34/48；圆角只有 4/6/8/15。
  • 08禁止间距自由取值：只有 2/4/6/8/10/14/18。出现 7/9/11/13/17/21 视为缺陷。
  • 09分类 chip 词条只能是图层名前缀原文。禁止「建筑 / 结构 / 机电」这类语义分类；前缀 = 按 - _ . 切第一段（1–8 字符，超长取前 3，统一大写），只有 ≥2 个图层才成组，其他 永远末位。
  • 10禁止把图层池折成 +N 浮层 / 横向滚动 / hover 才出现的 ＋。≥2 层一律「摘要行 → 行内展开」，chips 必须换行、行高必须变高。

  • 图标按钮 26×26、间距 2、图标 14；关闭按钮 32×48 贴右缘。
  • 内边距所有窗口左右 18；分组间距 14；表头与字段标签用 TextDim（不是 TextFaint）。
  • 主按钮每窗最多 1 个；并排的两个按钮等高（都是 32），独占时 34。
  • 列表行高 28（映射行 26），悬停 HoverRow，选中 SelectionBg + 左缘 2px，末行不画分隔线。
  • 旧色清零01 §9-19 列出的 10 个旧色值在本稿里只出现于「改造前」对照区与旧→新标注表，其余 artboard 一次都没有。
  • 图层池三形态0 层只有「＋ 选图层」；1 层是 chip + 常驻「＋ 再加一层」；6 层是摘要「6 层 · A-墙」+ 行尾 ＋，展开后 6 个 chip 换行成 2 行、行高变高、后续行被推下；16 层时 ＋ 置灰并挂 tooltip。

图层色块（12×12 / 8×8）取的是 ACI 调色板真实值（CAD 数据，不是 UI 主题色）； ACI 7（白）与灰阶色块统一加 1px 内描边，避免在深色底上消失。

09

防呆设计 与 漏画状态盘点

只补画代码里已经存在的失败分支 · 不新增功能、不改原逻辑

这套插件的设计理念从源码里能读出来：余光可见（胶囊条 / 3px 状态条）、 手不离光标（圆盘）、一次配好长期复用（配置）、 不打断命令流（高频操作零确认），以及最硬的一条—— 失败必须出声（代码注释原话：「存不进去就不能装作存好了，否则改动静默消失，用户还以为存上了」）。 所以本节的全部内容都是把这些已经写好的分支画出来：不新增确认框、不新增开关、不替换控件。 防呆 ≠ 多加弹窗；防呆是「不可逆要有名字和数量」「静默要有话说」「入口要常驻」「当前状态要余光可见」。

先认账：这轮设计稿删过 / 编过什么
判定标准只有一条：原来的功能优于被删后的形态，就恢复；只有证据表明原功能本身会出错，才保持移除并写清理由。
项判定依据 / 处理
CC 标题栏「打开主面板」（V1.0 的 ⚙）已恢复这是 CC → 主面板的唯一捷径，删掉是净损失。误点风险靠「与 ✕ 拉开 12 净空 + tooltip『打开主面板（QH）』」解决，不靠删按钮；图标只做风格统一（⚙ → 窗口 + 箭头），功能不变。见 03 节改造后。
设置窗口的三个「新开关」（扇区悬停高亮 / 显示胶囊条 / 应用后闪现）本轮删除全工程搜不到这些设置项，是设计稿凭空编的。已改回 V1.0 真实控件：点击录制快捷键框、触发方式四选一分段单选、长按时长滑杆、取消 + 保存。见 05 节。
CC 列表的「最近使用 / 全部图层」分组标题行保持移除，功能保留标题行能被 ↑↓ 聚焦、同名图层出现两次是真实缺陷；「最近」这项功能没删，已改为列表上方的常驻横向快捷行（不进列表、不抢键盘游标）。
「完成 / 确定」与「取消」并列的三按钮保持移除三个按钮语义重叠；底部收敛成一个主操作，文案本身就是结果预览。
◐ 主题切换待定，未擅自恢复源码 ApplyTheme 只作用 CC 一个窗口，恢复它等于恢复「一套插件两套皮肤」。要么做成全插件联动（需补齐浅色 token 表），要么维持单一深色——这是产品决策，留给用户拍板，不私自删也不私自加。
配置区 ⋯ 菜单 / 映射行 +N 浮层 / hover 才出现的 ＋ / 手打分号下拉已全部恢复前几轮已改回 V1.0：四个并列图标、摘要-行内展开、常驻 ＋、可编辑 PoolText 下拉。
A · 不可逆动作：给名字、给数量、给出路
删一整套配置、关窗丢改动、删掉最后一个图层——这三类一旦静默发生，用户要到画错之后才发现。

A1写盘失败：默认不关窗

没能保存
配置写不进 AutoLayer.ini（可能被别的 CAD 实例或杀毒软件占用，也可能没有写入权限）。关闭后，这次的改动会丢失。
留在面板仍然关闭

触发 点 X / Esc 时磁盘写不进去（PanelWindow.OnClosing 1243–1260）。给什么 默认不关 + 明写"改动会丢" + 具体文件名 + 一个明确的"仍然关闭"。不动什么 保存流程一行不改，只把已有分支画出来。

A2图层名不合法：当场改，不弹框

「A/墙」含 CAD 不允许的字符
不能出现 < > / \ " : ? * | , =；分号 ; 是多个图层的分隔符，也不能出现在图层名里。改掉才能保存。
→ 面板保持打开，光标回到这一行

触发 手打分号下拉里敲了非法名，关窗时被校验挡下（TryFindInvalidName 1246–1252）。给什么 提示行红字列出全部非法字符 + 面板不关。不动什么 不新增确认框——高频输入框里弹框会打断改字。

A3删配置：写清"一起删多少"

删除配置「建筑标准配置」？
这个配置里的 12 项映射会一起删除，无法撤销。
仅剩 1 个配置时，删除按钮置灰：至少要保留一个配置。
取消删除配置

触发 点配置区最右的红色 🗑（BtnDelete.IsEnabled = Profiles.Count > 1）。给什么 标题写配置名、正文写映射条数与"无法撤销"、仅剩一个时直接禁用。不动什么 四图标并列的结构不变，防误点靠常显红 + 分隔线。

A4删掉最后一个 chip：留撤销

设备　未设置 · 待配置　＋ 选图层
已删除「X-设备」　撤销（5s）　·　Ctrl+Z 可继续回退，直到保存 / 关窗

B · 静默失败：让"没发生"也有话说
